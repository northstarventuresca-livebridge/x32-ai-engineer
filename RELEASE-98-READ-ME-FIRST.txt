X32 AI ENGINEER — MULTI VOCAL RELEASE 98
==========================================

Windows launch package | November 15, 2026

WHAT TO RUN
-----------
1. Extract this entire ZIP to a folder on your Windows PC.
2. Close any older X32 AI Engineer bridge console first.
3. Double-click START-X32-ENGINEER.cmd in the TOP folder.
4. The bridge will open your browser to:
   https://x32-ai-engineer-church.globalconnectionschurch.workers.dev/

REQUIREMENTS
------------
- Windows and Python 3.10+ (same requirements as previous working bridge).
- Your existing X32 on the verified LAN, Dante Virtual Soundcard (DVS),
  and Chrome microphone permissions for your DVS receive devices.
- Cloudflare Access sign-in for the dashboard.

WHAT'S NEW IN RELEASE 98
------------------------
- Multi-select up to six mapped vocal microphones at once.
- Independent Dante audio sampling, speaking or singing mode.
- Waiting for candidate vocal activity before sending samples.
- Stop Listening for speaking, singing, or multi-select checks.
- Individual per-channel EQ result cards, modeled red/green curves.
- Per-channel Apply button with explicit confirmation and fresh EQ readback.
- Post-EQ audio monitoring is still NOT verified.
